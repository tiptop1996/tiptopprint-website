# TIP TOP OFFSET PRINTERS website

Static business website for TIP TOP OFFSET PRINTERS, Kodungallur, Kerala. Established in 1996.

## Publish

This site is configured for GitHub Pages and the custom domain `tiptopprint.com`.

- GitHub Pages source: deploy from the `main` branch, root folder.
- Custom domain: `tiptopprint.com` (the `www` address can redirect to this canonical domain).
- DNS: configure the four GitHub Pages A records at the apex and `www` CNAME to `tiptop1996.github.io` at Hostinger.
- Enable HTTPS in the repository Pages settings after DNS verification.

Files are plain HTML and static assets; no build step is needed.
